# 繰り返し指摘されたUX上の失敗

## ❌ ファーストビューの情報密度が低い

**何度も指摘された内容：**  
新しいUIコンポーネント（マイルストーンストリップなど）を追加するとき、縦に大きすぎてスクロールしないと主要コンテンツが見えなくなる。

**具体的な失敗例：**  
- マイルストーンストリップ：タイトル行 + 2行構成のチップで縦高さが60px以上になり、リストカードが画面内に入らなくなった

**守るべきルール：**  
- 通知・バナー系UIは **高さ 36px 以内** に収める
- タイトルラベルと内容を **同一行（横並び）** に収める
- チップ・バッジは **1行テキスト** のみ。アイコン + テキストを横並びで
- 「情報を追加する = 縦に積む」という発想をやめる。横スクロールか折りたたみで対応する

---

## ❌ カテゴリ選択UIが大きすぎる

**指摘：** 「カテゴリ欄大きいな。」  
**原因：** アイコンを上、テキストを下に縦並びにした大きいカードスタイルにした  
**修正：** アイコン＋テキストを横並びのコンパクトなピルに変更
